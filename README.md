# 安心护航 · 心理危机应急辅助系统

一个**单文件、离线可用**的心理危机应急 H5 工具。一线社工/咨询师或普通使用者在危机事件中，通过「选场景 → 勾情况 → 出方案」快速得到可执行的应急方案。

以 **PFA（心理急救）** 为底层框架，叠加危机干预、量表分流与转介功能。

> ⚠️ 本工具仅供辅助参考，**不能替代专业诊断与治疗**。量表结果为筛查而非诊断。遇紧急情况请立即拨打 110 / 120。

## 目录结构

| 文件 | 说明 |
|---|---|
| `index.html` | 主界面模板（含全部 CSS、视口检测脚本） |
| `data.js` | 场景、量表、热线、风险分级、强制报告、版权与版本信息 |
| `local-data.js` | 31 省本地热线、精神卫生中心、转诊资源 |
| `app.js` | 交互逻辑（方案生成、量表评分、主题/字号、屏幕适配） |
| `build.py` | 打包脚本：把上面 4 个文件内联成单个 HTML |
| `安心护航-心理危机应急助手.html` | **成品**：可直接用微信发送、离线打开的单文件 |

## 重新打包

修改源码后，运行：

```bash
python3 build.py
```

会生成 `安心护航-心理危机应急助手.html`（无外部资源依赖，纯离线单文件）。

## 使用与分发

- 把 `安心护航-心理危机应急助手.html` 直接发给对方，用手机浏览器打开即可，**无需联网**。
- 建议用带版本号的文件名分发（如 `...-v1.4.7.html`），避免微信/浏览器缓存旧版。
- 关于页可查看版本号、版权声明、PFA 对应关系与更新记录。

## 版本管理

- 版本号写在 `data.js` 的 `APP_META.version`，每次改动请同步更新并在 `changes` 里记录。
- 本仓库以 git 历史做版本管理；`.gitignore` 已忽略带版本号的历史成品文件。
